# **App Name**: TrackGuinea

## Core Features:

- Landing Page: Homepage with client/transporter signup buttons and service description.
- Client Registration: Client registration form: name, email, phone, password.
- Transporter Registration: Transporter registration form: name, email, phone, password, vehicle type, license upload.
- Client Dashboard: Client dashboard: create transport requests (city, arrival, nature, weight, date).
- Transporter Dashboard: Transporter dashboard: list available requests, apply, history, rating.

## Style Guidelines:

- Primary color: Saturated teal (#008080) for trustworthiness and efficiency.
- Background color: Light teal (#E0F8F8), subtly desaturated for a clean backdrop.
- Accent color: Analogous blue (#0080A9), brighter to highlight key interactions.
- Font pairing: 'Poppins' (sans-serif) for headlines, providing a precise, contemporary feel. 'PT Sans' (sans-serif) for body text, balancing modernity with warmth.
- Use clear, card-based layouts for requests and dashboards, ensuring easy navigation.
- Employ transportation-related icons to visually represent different request types.
